# Non-Local means
- Camera로 어두운 곳 사진을 찍으면 noise가 생김
- 전통적인 denoising filter들은 국소적 방식을 사용
- Noise를 지우기 위해 주변 pixel 값들을 평균 <= 가까운 pixels끼리는 색이 비슷할거라는 가정
- 위 방식을 사용시 영상의 중요한 경계선이나 미세한 질감까지 같이 흐릿하게 뭉개져 버림(blur)

## 1. Main idea
- 비슷한 무늬나 색상은 내 바로 옆뿐만 아니라, 영상 안의 다른 곳에도 반복해서 존재
- 영상 전체에서 가장 비슷하게 생긴 구역들을 찾고, 그 구역들의 중심점 값을 모아서 평균을 내자

## 2. 작동 원리
- 특정 pixel i의 noise를 제거한 깨끗한 값 NL(u)(i)는 영상 전체에 있는 모든 pixel j들의 값(u(j))을 가중합하여 구함

$$NL(u)(i) = \sum_{j \in I} w(i,j)u(j)$$

- w(i,j)는 단순히 두 pixel의 거리나 색상 차이로 결정되지 않음
1. Patch 단위 비교 : pixel i를 중심으로 하는 작은 사각형 구역과 pixel j를 중심으로 하는 작은 사각형 구역을 통째로 떼어내서 비교
2. 유사도 계산 : 두 patch 안에 모든 pixel 값들의 차이를 계산(L2 distance).
3. 가중 평균 : 비슷하게 생긴 구역에는 큰 가중치 부여

## 3. 장점과 단점

### 장점
- Detail 보존: 미세한 질감과 선명한 경계선 유지

### 단점
- 극심한 연산량
