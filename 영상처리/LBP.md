# 1.Local Binary Pattern

## 1. 작동 원리(Vanilla LBP)
- 영상의 모든 pixel을 순회하며, 각 pixel과 그 주변 이웃 pixel 간의 밝기 차이를 비교하여 8자리 이진수 부여

### 1-1. 임계값 처리
- 이웃 픽셀이 중심 픽셀과 같거나 더 밝으면 -> 1
- 이웃 픽셀이 중심 픽셀보다 어두우면 -> 0

### 1-2. 실제 값 대입 및 이진화 연산
- 시계 방향 또는 반시계 방향으로 이진수를 한 줄로 나열
- 가중치 곱 계산
- Ex) 이진수 나열 : 1 0 1 1 1 1 0 0
- $2^0$부터 $2^7$까지 할당
- $1 \times 2^7 + 0 \times 2^6 + 1 \times 2^5 + \cdots + 0 x 2 + 0 x 1=188$
- 중심 픽셀값은 텍스처 정보가 반영된 188로 치환

# 2. Circular & Multiscale LBP
- 3 x 3 고정 크기에서 벗어나기 위해 제안
- 반지름 R과 이웃 픽셀 수 P를 매개변수화하여 원형 구조로 이웃을 정의
- 카메라와 안면 간의 거리가 달라져서 생기는 크기 변화에 강건해짐

# 3. Uniform Patterns
- 256가지의 이진 패턴 중 실질적으로 의미 있는 유효 패턴은 소수에 불과
- 이진수 루프를 회전시킬 때 0에서 1로, 혹은 1에서 0으로 변하는 횟수가 2회 이하인 패턴
- 000000 -> 변화 0번
- 110011 -> 변화 2번
- 노이즈를 배제한 가장 정밀한 가장자리, 평면 텍스처만 남김.

# 4. PAD에서 LBP를 사용하는 이유
- 인쇄지 질감 감지 : 종이에 인쇄된 사진은 잉크 방울이 뭉치거나 종이 섬유의 거친 단면이 미세한 음영을 만듦
- LBP는 이 미세한 고주파 음영 패턴을 부각시킴
- 조명 불변성 : LBP 연산의 가장 큰 장점은 절대 밝기 수치에 무관.
