# 1. 1:1 검증
- 이 사람이 등록된 A가 맞는가?
- 등록된 얼굴과 촬영한 얼굴을 비교
- 유사도 점수가 암계값 이상이면 동일인으로 판단
- 평가에서는 동일한 쌍과 타인 쌍의 점수를 각각 모아 두 종류의 오류를 측정

|지표|측정|예|
|--|-------|-----|
|FMR(False Match Rate)|타인 비교 중 임계값을 통과한 비율|타인 비교 10,000건 중 1건 통과 -> 0.01%|
|FNMR(False Non-Match Rate)|동일한 비교 중 임계값을 통과하지 못한 비율|동일인 비교 1,000건 중 20건 거부 -> 2%|

- 임계값을 높이면 타인이 통과하기 어려워지고, 본인도 거부될 가능성이 커짐
- 허용할 FMR을 정하고, 그 수준에서 FNMR이 얼마나 낮은가를 비교

# 2. 1:N 확인
- 이 사람이 등록자 중 누구인가?
- 새로 촬영한 얼굴을 probe, 등록된 얼굴 집합을 gallery라고 함

|지표|측정|예시|
|--|-------|-----|
|FPIR(False Positive Identification Rate)|미등록자 검색 중 임계값이 넘은 후보가 하나 이상 나온 비율|미등록자 검색 1,000건 중 3건에서 후보 발생->0.3%|
|FNIR(False Negative Identification Rate)|등록자 검색 중 정답 인물을 기준에 맞게 변환하지 못한 비욜|등록자 검색 500건 중 10건에서 정답 반환 실패->2%|
